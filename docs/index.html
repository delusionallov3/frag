Features

Everything after the game.

Auto-record with OBS

Starts at agent select or when the game loads, stops a few seconds after. Recordings get renamed: map, mode, score. If Valorant opens without OBS, you get a notification and one click starts it.

Privacy

Your games stay on your PC.

No account, no cloud, no tracking. Frag only talks to the internet for match data, game images and updates.

  • Local files. Clips, notes and settings live in your AppData folder.
  • Encrypted secrets. Your HenrikDev key and OBS password are stored with Windows encryption.
  • Hands off the game. Frag reads the Riot client's local status, the same one Discord uses. It never touches the game itself.
FAQ

Questions

Windows says it protected my PC. Is that normal?

Yes. Frag isn't code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway. The installer comes straight from the GitHub releases of this project.

Do I need OBS?

Only for auto-record. You can also drop any recording into Frag and clip it by hand. For auto-record, turn on OBS's WebSocket server (Tools → WebSocket Server Settings) and paste its password into Frag.

What's the HenrikDev key for?

It's how Frag gets your match data: kills, rounds, scoreboard. The key is free at api.henrikdev.xyz. Without it you can still record, clip and export.

My keyboard is AZERTY.

Switch the keyboard layout in Settings. Letter shortcuts work everywhere, and the symbol ones follow your layout (à to fit the timeline, ; for next).

Does it cost anything?

No. Frag is free.
